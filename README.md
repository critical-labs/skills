# Critical Labs — Claude Code Skills

Reusable [Agent Skills](https://agentskills.io) for Claude Code: agent workflows and orchestration playbooks.

Install a skill by copying its directory into `~/.claude/skills/` (personal) or `.claude/skills/` (project).

## Skills

- [github-agent-team-orchestration](github-agent-team-orchestration/SKILL.md) — run an unattended team of worker agents against a GitHub issue backlog: bot-identity fork PRs, cross-review ring, maintainer-first PR babysitting, and usage-limit-surviving supervision.
